# Codelinear Assignment Frontend Scaffold

A production-ready Next.js foundation for pixel-perfect responsive UI work.

## Highlights

- Next.js App Router with TypeScript
- Tailwind CSS design system setup
- ESLint + Prettier tooling
- Absolute imports via `@/*`
- Reusable shared components and layout foundation
- Responsive mobile-first architecture
- Semantic markup and accessible UI primitives

## Project structure

- `src/app` — application routes and layouts
- `src/components` — reusable UI components
- `src/lib` — utilities and font setup
- `src/constants` — site-level constants
- `src/types` — shared TypeScript types
- `public` — static assets

## Next steps

1. Add new app routes in `src/app` per Figma pages
2. Build components in `src/components/ui` and `src/components/shared`
3. Use Tailwind utility classes for responsive spacing and typography
4. Keep pages server components unless interactivity is required
5. Run `npm dev` locally after dependencies are installed
